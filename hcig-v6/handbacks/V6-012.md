# Handback: Ticket V6-012 (Official logo hunt for the gap list)

## 1. Summary of Work Done
Collected the best official logo file for each organisation on the gap list specified in the brief. Vector formats (SVG) were prioritised first, followed by the largest official transparent PNG files in brand colours. All assets preserve original file bytes directly from official servers or verified Wikimedia Commons public domain records. No aggregator websites, no AI redraws, and no tracings were used.

All collected files are placed in `hcig-v6/incoming/V6-012/` together with a complete provenance inventory in `hcig-v6/incoming/V6-012/SOURCES.md`.

## 3. How Each Source Was Verified As Official
- MedOne Group: Fetched from the official operational website `https://medoneclinic.net/assets/images/logo.png`. Cross-referenced with the brand's verified LinkedIn showcase (`linkedin.com/showcase/medoneclinic/`).
- MedPark Health Group: Inspected `https://medparkhospitals.com/`. Verified the live header element (`logo.webp`) and extracted the official 1500x1500 px master JPEG (`logo.JPG`) declared in site schema and open graph headers.
- One Medical Center: Crawled `https://www.onemedicalcenters.com/` directly. Extracted the vector SVG asset declared in the main navigation bar.
- One Medical Spa: Crawled `https://www.onemedspa.net/` directly. Located the header image and retrieved the full resolution transparent master PNG from the CDN origin (`Spa+(2).png`).
- UCA MENA: Inspected `https://ucamena.org/`. Retrieved the raw uncompressed lossless PNG (`blob-0001.png/:/ll`) from the GoDaddy hosting CDN, preserving full 1280x1258 px resolution.
- SCMG: Checked `https://scmg-egypt.com/`. Extracted the header brand asset `themes/en/images/logo.png`.
- GHA: Inspected `https://www.globalhealthcareaccreditation.com/`. Confirmed the site header brand image is the stacked logo (`GHA Stacked Logo-01.png`), distinct from the circular accreditation seals.
- DMWV: Crawled `https://www.dmwv.de/`. Located static assets in Next.js public storage and retrieved both the German association header logo (829x849 px) and the 1600x1600 px international version.
- CSS Insurance: Checked `https://www.css.ch/en/home.html` where the header contains an inline SVG with viewBox `0 0 68 29` and brand fill `#00A4E0`. Retrieved the official vector SVG matching these exact paths from Wikimedia Commons (`File:Css-versicherung-logo.svg`, public domain).
- Allianz Partners: Loaded `https://www.allianz-partners.com/` in an active browser session. Downloaded the header logo (`AZ_Partners_Attached_Descriptor_Positive_RGB_.png`) directly from the OneMarketing Adobe Experience Manager DAM.
- ITB Berlin: Loaded `https://www.itb.com/en/`. Retrieved the official vector SVG `ITB_26_Logo_Berlin_279x86px.svg` hosted on the Messe Berlin e-Spirit cloud CDN.
- ITIC: Inspected `https://www.itic.co/`. Downloaded the official theme vector logo `logo-itic.svg` from the WordPress theme directory.
- Africa Health ExCon: Inspected `https://www.africahealthexcon.com/`. Downloaded the official header logo `images/logo.png`.
