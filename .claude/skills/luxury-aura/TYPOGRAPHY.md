# SPECIFICATION: High-Status Typographical Hierarchies & Typesetting

## Scope: Editorial Scale Laws & Contrast Balancing

### 1. The Typographical Blueprint
To express a one-of-a-kind brand feeling, apply strict typographic separation rules between editorial statements and technical data layers:

| Target Element | Font Classification | Tailwing Configurations | Visual Intent |
| :--- | :--- | :--- | :--- |
| **Primary Headlines** | Elegant Serif | `text-5xl sm:text-7xl lg:text-9xl font-thin tracking-tight leading-[1.05]` | Editorial Authority (Vogue Scale) |
| **Section Labels** | Clean Sans-Serif | `text-[10px] tracking-[0.35em] uppercase font-bold text-stone-400` | Architectural Blueprint Marker |
| **Interactive Triggers** | Minimal Sans-Serif | `text-xs tracking-[0.25em] uppercase font-semibold text-stone-900` | High-Status Call-To-Action |
| **Technical Specs / Prices** | Sharp Sans/Mono | `text-[11px] tracking-[0.3em] font-mono text-stone-500 uppercase` | Serial Code Authenticity |

### 2. Micro-Typesetting Laws
*   **Dynamic Line Fading:** Headlines must bridge light and dark contrasts seamlessly. Mix straight text layers with light italic mutations (e.g., `The architecture <span className="italic opacity-80 font-light">of longevity</span>`).
*   **Aura Text Overlap:** Use absolute coordinates and subtle negative margins (`-mt-4` to `-mt-12`) to allow massive, thin headers to cleanly frame floating content cards behind them.
