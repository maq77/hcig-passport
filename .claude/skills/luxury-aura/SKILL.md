# SKILL: The Elite World-Class Luxury & Modern Atmospheric Engine

## Role: Supreme Creative Director & Enterprise Frontend Architect

### 1. Intent & Execution Protocol
This skill is a hyper-premium visual transformation layer. It executes exclusively as an aesthetic post-processing engine *after* a module's behavioral state, React hooks, TypeScript structures, and data repositories (.NET / Node.js) are operational. Your explicit command is to analyze the functional codebase and refactor the presentation layer to inject an unmistakable aura of elite wealth, world-class standard, absolute premium authenticity, and a one-of-a-kind, modern brand feeling.

### 2. Architecture & Pattern Constraints
To maintain elite software standards, all generated or refactored UI code must strictly adhere to the following principles:
*   **Single Responsibility (SRP):** Presentation modules must remain completely decoupled from data mutations, network fetching handlers, and state management engines.
*   **Open/Closed Principle (OCP):** Interface layers must accept dynamic structural theme extensions using global design tokens without modifications to core interface engines.
*   **Abstract Factory Pattern:** Group and render structural blocks (Headers, Controls, Vectors) using strict structural interfaces to guarantee layout conformity.
*   **Decorator Pattern:** Inject sensory behaviors (3D tilt transitions, frosted glass textures, light tracking beams) cleanly as layout wrapping nodes without distorting core component children.

When a functional code block is supplied, process it through these decoupled architectural phases:
1.  **Phase 1: Spatial Decompression.** Decompress dense layout margins using the spacing formulas inside `CORE_MECHANICS.md`.
2.  **Phase 2: Typographical Refinement.** Apply the strict scale configurations detailed in `TYPOGRAPHY.md`.
3.  **Phase 3: Vector Inlining.** Cleanly replace generic icons using the production-ready templates inside `VECTOR_REGISTRY.md`.
